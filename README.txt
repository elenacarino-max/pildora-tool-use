# Web de presentación · Tool Use

Archivo principal: `index.html`

## Uso
1. Abre `index.html` con Chrome o Edge.
2. Usa el menú lateral o las teclas ↑ ↓ para avanzar.
3. En la sección "Demo simulada", pulsa "Avanzar demo" para revelar el flujo paso a paso.

No necesita servidor, API ni conexión a Internet.
