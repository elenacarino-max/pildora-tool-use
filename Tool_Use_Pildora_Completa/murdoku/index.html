Murdoku: ¿qué ocurrió en el sistema?

Cuatro ejecuciones, cuatro herramientas y cuatro resultados distintos. Usa las pistas para reconstruir qué hizo cada agente y qué fallo encontró.

Contexto. El equipo revisa cuatro trazas de un sistema con Tool Use. Cada agente utilizó una herramienta distinta: Tiempo, Agenda, Base de datos o Correo. Y cada ejecución tuvo un resultado diferente: correcta, argumento inválido, tool no autorizada o permiso insuficiente.

Pistas

No hace falta saber código: solo aplicar la lógica y lo aprendido en la píldora.

1El Agente A completó correctamente su ejecución y no utilizó ni Agenda ni Correo.
2La herramienta Agenda recibió una fecha con formato incorrecto.
3El Correo intentaba realizar una acción sensible y debía requerir confirmación antes de ejecutarse.
4El Agente C no utilizó ni Tiempo ni Agenda.
5El Agente D fue quien intentó realizar una acción que podía afectar a un usuario externo.
6La tool no autorizada fue solicitada por el Agente C y se bloqueó antes de ejecutarse.
