RECOMENDADO: GITHUB PAGES
1. Crea un repositorio nuevo en GitHub, por ejemplo: pildora-tool-use
2. Sube TODO el contenido de esta carpeta manteniendo las carpetas murdoku y colab.
3. En GitHub entra en Settings > Pages.
4. En Build and deployment elige: Deploy from a branch.
5. Branch: main / root. Guarda.
6. GitHub mostrará una URL parecida a:
   https://TU_USUARIO.github.io/pildora-tool-use/
7. Abre esa URL. La presentación y el Murdoku funcionarán directamente.
8. El botón "Abrir práctica en Colab" detectará automáticamente el usuario y repositorio de GitHub Pages y abrirá el notebook en Google Colab.

USO LOCAL
- Abre index.html con Chrome o Edge.
- El botón Murdoku funcionará.
- Como no estás en GitHub Pages, el botón Colab descargará el archivo .ipynb para que puedas subirlo manualmente a Google Colab.
